# GamePulse
GamePulse — ваш персональный гид в мире игр. Система анализирует не только жанры, а паттерны вашего удовольствия, чтобы рекомендовать тайтлы, которые зайдут именно вам. Добавляйте друзей, чьему вкусу доверяете, — их оценки станут для вас лучшей рекламой. Ведите детальный игровой архив, вступайте в тематические клубы и находите единомышленников.
